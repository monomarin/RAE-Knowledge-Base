# Internal Developer Platform (IDP)

> Official Internal Developer Platform for RAE Platform.

---

# Executive Summary

The Internal Developer Platform (IDP) provides a standardized self-service platform that allows engineering teams to build, deploy and operate software without requiring deep infrastructure knowledge.

Platform Engineering treats the platform as an internal product.

Developers become customers of the platform.

---

# Vision

Provide the fastest, safest and most productive software delivery experience for every engineering team.

---

# Strategic Objectives

- Self-Service Engineering
- Standardized Development
- Faster Delivery
- Reduced Cognitive Load
- Secure Defaults
- Platform Reusability
- AI-Assisted Development
- Enterprise Governance

---

# Core Principles

The Internal Developer Platform shall be:

- Self-Service
- API First
- Cloud Native
- Secure by Default
- Observable
- Automated
- Developer-Centric
- AI-Enabled

---

# Platform Services

The platform provides:

- Repository Templates
- Project Bootstrap
- Kubernetes Provisioning
- Secrets Management
- CI/CD Pipelines
- Monitoring
- Logging
- Alerting
- Service Catalog
- API Gateway
- AI Platform Services
- Documentation Portal

---

# Self-Service Capabilities

Developers shall be able to:

- Create new services.
- Request infrastructure.
- Provision databases.
- Generate APIs.
- Deploy applications.
- View logs.
- Access dashboards.
- Request secrets.
- Manage environments.
- Consume AI services.

No manual ticket should be required for standard workflows.
